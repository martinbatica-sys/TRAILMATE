# Trailmates — Landing Page

Sitio web para el paquete experiencial del Cruce de los Andes 2026.

## Estructura

```
trailmates/
├── index.html        ← página principal
├── assets/
│   ├── portada.mp4   ← video hero (portada)
│   ├── portada.jpg   ← foto grupo runners
│   ├── casa1.jpg     ← interior casa (ventanal montaña)
│   ├── casa2.jpg     ← interior casa (lámparas + escalera)
│   ├── casa3.jpg     ← interior casa (cerro nevado)
│   ├── refugio.jpg   ← refugio atardecer
│   └── spot_cerro.jpg ← spot base Catedral
└── README.md
```

## Cómo usar

Abrí `index.html` en cualquier navegador. Para que el video funcione tiene que estar la carpeta `assets/` en el mismo lugar que el `index.html`.

## Para publicar online

Subir todo el contenido de esta carpeta a:
- **Vercel**: arrastrar la carpeta a vercel.com/new
- **Netlify**: arrastrar a netlify.com/drop
- **GitHub Pages**: subir a un repo y activar Pages
